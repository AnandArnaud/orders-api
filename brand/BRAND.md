# Nimbus brand

Nimbus makes simple, well-made basics: a tee, a mug, a cap, a tote. The brand is calm, airy and
precise.

## Colours

| Role | Hex |
| --- | --- |
| Sky (primary, accents) | `#3B6FB5` |
| Ink (headings, body text) | `#1F2430` |
| Mist (page background) | `#F3F6FA` |
| Cloud (cards, surfaces) | `#FFFFFF` |
| Haze (borders, dividers) | `#D9E1EC` |
| Sun (secondary accent, used sparingly) | `#E8B04B` |

Light backgrounds, dark text. Sky is the only saturated colour; use it once per composition.

## Type

Headings: a geometric sans, tight letter spacing. Body: the same family at a comfortable size.
Prices are set in the body colour, never in Sky.

## Logo

`logo.svg` is a rounded Sky square carrying a small cloud. Minimum size 24 px. Keep clear space of
half the mark's width around it. Do not recolour it.

## Voice

Plain, specific, unhurried. Name the material and the fit. No exclamation marks, no superlatives.

## Customer cards

Square (1080 x 1080). The customer's first name, what they ordered and the order number, on Mist,
with the Nimbus mark bottom right. One order per card.
